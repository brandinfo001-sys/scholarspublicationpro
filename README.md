# Scholars Publication Pro Website — Premium Revision

Responsive multi-page static website rebuilt for a more distinctive, trust-focused academic publication-support brand.

## Pages
- index.html — premium homepage
- services.html — five grouped service areas
- about.html — approach, quality workflow and integrity
- contact.html — consultation and manuscript contact flow
- privacy.html
- terms.html
- 404.html

## Key improvements
- Replaced external stock photography with original local SVG academic illustrations.
- Reorganized services into five understandable categories.
- Added a seven-stage research-to-publication journey.
- Added specialist-workflow, integrity, confidentiality and illustrative editing sections.
- Removed pseudo-statistics and unsupported success claims.
- Improved mobile menu behavior, Escape-key close, link-close and mobile topbar visibility.
- Reduced animation to major visual elements only.
- Added Open Graph/Twitter metadata, a web manifest and a custom 404 page.

## Forms
The website remains deployable on static hosting such as GitHub Pages. Consultation forms intentionally use `mailto:` rather than silently routing unpublished research through an unknown third-party form processor. Manuscript submission opens a prepared email and asks the user to attach files manually.

For true direct form submission and secure file uploads, connect the forms to a backend you control or a vetted provider and update the Privacy Policy to match that processor. This requires deployment/account credentials and cannot be completed safely with a static ZIP alone.

## SEO before final domain launch
Once the production domain is known, add canonical URLs, absolute Open Graph URLs and a sitemap.xml using the real domain.

## GitHub Pages
Upload the contents of this folder to the repository root, then enable Settings → Pages → Deploy from a branch.
